# H2语义与修复边界

## 固定的物理问题

μ>0，0<r₁<r₂；平面固定中心牛顿引力；初末圆轨道同向；点火时间零；成本是各次实际速度跳变的欧氏范数之和。
两次脉冲竞争者允许非零径向端点速度、负滑行角动量、双曲/抛物能量、任意端点方位和有限滑行时间。不得以这些额外限制简化证明。

## 两种结构的角色

`EndpointData`/`PhysicalEndpoints`定义端点松弛可行集合，能量角动量相等是这个集合的约束，并非声称任意端点都可实现。
`KeplerArc`定义真实动力学可行轨迹：位置导数是速度，速度导数是牛顿引力。其能量角动量守恒由证明导出。
这样的ODE假设用于“对所有可行竞争者”的最优性问题是必要定义，不是把最优性或守恒结论塞入假设。
`H1Bridge`另证已显式构造的H1轨迹取到同一下界，所以核心松弛下界不会孤立停留在不可达到的最优值。

## 不可弱化的主结论

- 任意正μ和任意0<r₁<r₂的两脉冲下界。
- 两个脉冲分别的下界，不只是一个数值例子。
- 等号端点径向速度为零，切向速度与霍曼一致。
- 实际笛卡尔欧氏速度跳变，而非人为定义的成本等式。
- 1→64→16有限反例及严格gap>9/1000。
- H1轨迹达到下界与实际反例轨迹属于full验证范围。

## 不能宣传

“所有变轨方案都最优”“固定时间/会合最优”“唯一完整轨迹”“有限推力最优”“双椭圆例子是三脉冲全局最优”“所有引擎实际燃料最优”“全球首个形式化”。
H2未重新实现一般火箭方程；Fuel为已给定理想模型的条件推论。
